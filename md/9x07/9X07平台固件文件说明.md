# MDM9607 平台固件文件说明

## 1. 主要固件文件列表

| 序号 | 文件名 | 类型/描述 | 备注/注意事项 |
| :--- | :--- | :--- | :--- |
| 1 | `appsboot.mbn` | Linux Aboot 文件 | Android Bootloader。 |
| 2 | `cefs.mbn` | CEFS 文件 | &zwnj;**工厂版本采用**&zwnj;。<br>⚠️ &zwnj;**注意**&zwnj;：一旦升级 CEFS 会导致工厂校准参数丢失。虽然能搜到网络，但 IMEI 等参数会恢复到默认值。<br>*(注：Scrubs 机制未使用)* |
| 3 | `data.ubi` | UBI 文件系统固件 | 读写数据分区。 |
| 4 | `ENPRG9x07.mbn` | 下载精灵 (Emergency Downloader) | &zwnj;**当前基本已不再使用**&zwnj;。<br>实际不写入 Flash，而是由工具进入 Sahara 模式后先加载到片内 RAM 中执行。包含下载协议及对应平台的 Flash/DDR 驱动，控制后续 Bin 文件的下载过程。 |
| 5 | `factory.xqcn` | - | 实际上不下载，无实际用途。 |
| 6 | `mdm9607-boot.img` | Linux Boot Image | 包含 Linux 内核。 |
| 7 | `mdm9607-recovery.ubi` | Recovery FS 文件系统 | 恢复模式文件系统。 |
| 8 | `mdm9607-sysfs.ubi` | Linux Rootfs 文件系统 | 系统根文件系统。 |
| 9 | `NON-HLOS.ubi` | Modem Bin 文件存放文件系统 | 非高通操作系统部分（基带相关）。 |
| 10 | `NPRG9x07.mbn` | 下载精灵 | 同 `ENPRG9x07.mbn`。 |
| 11 | `oemapp.ubi` | Softsim 相关文件系统 | OEM 应用数据。 |
| 12 | `partition.mbn` | 分区表 | &zwnj;**Sahara 模式使用，基本已废弃**&zwnj;。 |
| 13 | `partition_nand.xml` | 下载文件列表描述文件 | &zwnj;**Sahara 模式使用，基本已废弃**&zwnj;，但现在作为分区配置表制作的基础文件。<br>通过该 XML定位哪个分区下载哪个 Bin 文件。 |
| 14 | `rpm.mbn` | 电源管理固件 | Resource Power Manager。 |
| 15 | `sbl1.mbn` | Secure Bootloader (SBL1) | 负责执行最早期的硬件初始化、安全检查以及加载后续启动阶段所需组件。 |
| 16 | `tz.mbn` | 安全管理固件 | TrustZone。 |
| 17 | `usrdata.ubi` | 用户数据文件系统 | 与 `data.ubi` 类似。 |

## 2. Firehose 目录及相关文件

Firehose 下载方式所需的配置文件和驱动：

*   &zwnj;**`partition_complete_p4K_b256K.mbn`**&zwnj;
    *   Firehose 下载方式的分区表。
*   &zwnj;**`patch_p4K_b256K.xml`**&zwnj;
    *   Firehose 下载方式的下载配置表补充文件（Patch 文件）。
*   &zwnj;**`prog_nand_firehose_9x07.mbn`**&zwnj;
    *   下载驱动程序 (Programmer)。
*   &zwnj;**`rawprogram_nand_p4K_b256K_factory.xml`**&zwnj;
    *   Firehose 下载方式的下载配置表（Raw Program 文件）。
